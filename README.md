# 🎓 Student Management System

A simple web-based Student Management System developed to manage student records efficiently.

## 🚀 Features
- ➕ Add Student
- ✏️ Update Student Details
- ❌ Delete Student
- 🔍 View Student Records
- 📋 User-friendly Interface

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📂 Project Structure
```
student-app/
├── index.html
├── style.css
├── script.js
```

## ▶️ How to Run
1. Clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
